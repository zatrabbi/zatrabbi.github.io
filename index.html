KUASHAকুয়াশা

2026 · in production

A bilingual e-commerce store for a winter-clothing business in Bangladesh.

  • Every page switches between Bangla and English, including the owner's admin panel.
  • PostgreSQL schema on Supabase for products, colour/size variants, orders, reviews and Q&A, with row-level security on every table.
  • Prices, stock and delivery charges are calculated in the database, so a customer cannot change a price from the browser.
  • Cash-on-delivery and bKash/Nagad checkout, order tracking by order number and phone, and confirmation emails in the customer's language.
  • Multi-stage Docker image with a health check; GitHub Actions runs tests, a production build and a container smoke test on every push.

PapayaFusionNet

2026 · B.Sc. thesis, team

Diagnosing papaya leaf diseases from photos taken in Bangladeshi fields.

4,436images we photographed, 6 classes
10CNN and transformer models, 3 seeds each
97.75%best test accuracy (MaxViT-Tiny)

Test accuracy, mean ± standard deviation over 3 random seeds, for 7 of the 10 models we benchmarked.

  • Labels verified by a plant pathologist at the Bangladesh Agricultural Research Council.
  • Removed exact and near-duplicate photos with perceptual hashing, then audited the 70/15/15 split for leakage.
  • An external test set scored 70.2%, which showed a real-world domain shift that the thesis analyses.
  • Built PlantSense AI, a web app that diagnoses a leaf from a single photo using the best model.
