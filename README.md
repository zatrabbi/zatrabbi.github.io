## Featured projects

### [KUASHA](https://kuashabd.netlify.app) — bilingual e-commerce platform
A full-stack store for a real winter-clothing business, with an English/Bangla language switch, an admin dashboard, cash-on-delivery and bKash/Nagad checkout, order tracking and order-confirmation emails.
Dockerised with a multi-stage build and tested on every push with GitHub Actions.

`Next.js` `React` `Supabase` `PostgreSQL` `Docker` `GitHub Actions` · **[Live site](https://kuashabd.netlify.app)**

*The source code is private because this is a live business; I am happy to walk through it on request.*

### [BookBazar](https://github.com/zatrabbi/Django-project-Bookbazar-E-Commerce-platform.-) — Django bookstore
An online bookstore with email-based accounts, nested categories, search, a cart and wishlist, promo codes, Stripe card payments and staff tools for managing books. Covered by 26 automated tests.

`Python` `Django` `SQLite` `Stripe` `Bootstrap` `GitHub Actions`

### PapayaFusionNet — B.Sc. thesis (team)
Papaya leaf disease classification on a 4,436-image dataset my team collected in Bangladesh, with labels verified by a plant pathologist. We benchmarked 10 CNN and vision-transformer models over 3 seeds; the best, MaxViT-Tiny, reached 97.75 ± 0.45% test accuracy. We also built PlantSense AI, a web app that diagnoses disease from a leaf photo.

`Python` `PyTorch` `timm` `Kaggle`
